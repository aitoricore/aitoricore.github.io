Q：为什么要搭 blogs？

A：因为很好玩，这样的理由就足够了吧。另一方面洛谷如今不在国内提供博客阅读服务了，cnblogs 公开文章要等审核，一怒之下就这么做了。

我写的东西随着洛谷博客流量的下降已经彻底 0 人观看了，然后用户彻底怒了，其结果就是你现在正在看的东西。

Q：怎么搭这样的静态博客网站？

A：大概在四五年前这还挺麻烦，如今有 ai 的时代已经非常容易了吧。

安装好 chatgpt 推荐的工具，把 github copilot 的免费额度烧完就做完了，然后往 github 上一挂。诚恳地邀请您将同样的事情当作一个简单的小练习……这不会花费多于三天完成。

简单以外，我想这个过程还挺有教育意义的。学会了 git 的基本操作，一点 css、html 和 Go……为以后进厂打工然后被 ai 优化奠定了良好的基础。

Q：黄色的这个主题好丑。

A：newsprint 风格有没有人懂啊……就算这样也是从 terminal 主题一路艰苦爆改过来的——css 的明确度规则怎么这么诡异啊？？在这个问题上 ai agent 也帮不上你，它没有什么审美。

很快就会上线深色模式和其他主题，在那之前请忍耐。

Q：有一部分发布在洛谷上的博文没有搬过来？

A：手工处理标签和标注信息意外地麻烦，而我又没有 agent 额度了……还有，太唐的博文也不搬了。

如果你觉得现在的有些文章已经很唐了，别笑还有第二关。

Q：Ait、Aya（Shameimaru_Aya）、Aitoricore 都是什么？

A：由于历史原因，我在不同的网站上用不同的马甲……现在迁移到一块的时候有些身份混乱。

粗略地，你可以认为在页面上出现的所有首字母大写的 A 一串英文都是我。

——对，包括 Answer 的 A。

Q：我还有想问的问题不在这个列表里。

A：求你了，联系我 好不好。任何反馈，从建议到吐槽，都非常欢迎。
